# Backend Developer Guide

## Setup

```powershell
cd backend
npm install
npx prisma generate
npx prisma migrate dev
npm run seed
npm run dev
```

The API listens on `http://localhost:5000` by default. Copy `.env.example` to `.env` and configure `DATABASE_URL`, `JWT_SECRET`, `FRONTEND_URL`, and the Cloudinary credentials before starting the server.

## Deploying to Vercel

Deploy the `backend` directory as its own Vercel project. The project includes `api/index.js` as the serverless entry point and `vercel.json` to route `/api/*` requests to it. Configure all production environment variables in Vercel Project Settings. Never commit `.env` files or production secrets.

## API conventions

- Public endpoints are under `/api`: `GET /health`, `GET /settings`, `GET /categories`, `GET /posts`, `GET /posts/:slug`, `GET /search`, `POST /newsletter`, and `POST /author-requests`.
- Admin endpoints are under `/api/admin` and require `Authorization: Bearer <jwt>`.
- Roles are `SUPER_ADMIN`, `ADMIN`, `EDITOR`, and `AUTHOR`. Use the `roles(...)` middleware for role-restricted routes.
- JSON errors use `{ "message": "..." }` and successful mutation endpoints return the created or updated record.
- Public GET responses have short cache headers. Admin responses are not cached.

## Database workflow

1. Change `prisma/schema.prisma`.
2. Run `npx prisma migrate dev --name describe-change` locally.
3. Run `npx prisma generate` if the client is not regenerated by migration.
4. Commit the generated migration directory. Do not commit local database files.

## Media uploads

`POST /api/admin/media/upload` accepts a raw image body with `Content-Type` and `X-File-Type` headers. Supported formats are JPEG, PNG, WEBP, and GIF, with a maximum size of 5 MB. The server validates the type and size before sending the image to Cloudinary, then stores the returned URL and metadata in `Media`.

## Authentication

Login is `POST /api/auth/login` with `{ "email": "...", "password": "..." }`. JWTs use `JWT_SECRET` and `JWT_EXPIRES_IN`. Replace the seeded password and rotate any credentials that have been exposed outside a private environment.
